Place optional command/unit icons here as PNG files.
Filename = type_name or order keyword, e.g. peasant.png, townhall.png, train.png
Size: any; will be scaled to 48x48 (commands) or 32x32 (queue).
If missing, the HUD generates a colored letter icon automatically.

Starter pack (flat geometric silhouettes) was generated by:
  python tools/gen_hud_icons.py
Replace any file with better art anytime; same filename wins.
