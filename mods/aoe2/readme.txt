帝国时代2决定版风格模组（12文明）
=====================================

数据来源见 SOURCES.md（biligame wiki + aoe2.tw + aoe2techtree）。

启用
----
  mods = aoe2


文明（biligame）
--------------------
1. 不列颠 — 长弓兵；英皇侍卫 / 战狼号；无血统、无扳指
2. 法兰克 — 掷斧兵 / 游侠；骑士精神 / 芒刺斧；骑兵高血；无扳指、无护腕、无射手锁甲、无血统
3. 中国 — 诸葛弩；长城 / 火箭术；村民更便宜；无帕提亚、无攻城技师
4. 蒙古 — 蒙古突骑；游牧 / 操练；骑射攻速；草场替农田、无磨坊；无板甲马铠、无射手锁甲
5. 拜占庭 — 甲胄骑兵；希腊之火 / 后勤学；建筑更硬更便宜；无鼓风炉、无血统
6. 日本 — 武士；射箭孔 / 弹射器；步兵攻速；无板甲马铠、无建筑学、无炮塔
7. 条顿 — 条顿骑士；重装甲 / 开垛口；步兵高甲、农田便宜；无护腕、无扳指、无轻骑
8. 维京 — 狂战士 / 长船；酋长 / 弓矛兵；步兵高血；无血统、无扳指、无长戟
9. 越南 — 藤甲弓兵 / 帝王掷矛手 / 象兵；宝伞 / 纸币；弓兵高血；无鼓风炉、无帕提亚
10. 葡萄牙 — 风琴炮 / 卡拉维尔 / 大商站；环球航行 / 火绳枪；船只高血；无侍从、无垛口
11. 阿兹特克 — 美洲豹武士 / 鹰勇士；投矛器 / 花环战争
12. 凯尔特 — 靛蓝突袭者；堡垒 / 凯尔特狂暴；步兵移速、伐木、攻城射速；无双手剑/冠军、无扳指/护腕/血统/游侠

特色科技效果（对齐 DE，非近似）
--------------------------------
射箭孔：塔额外射箭（``rdg_seq``）；弹射器：攻速 + 打包/拆包时间；开垛口：城堡射程 + 驻军步兵射箭；
酋长：对骑兵/骆驼加成 + 杀村民/贸易/僧侣得金；纸币：伐木时产金；环球航行：全图探索 + 造船加速；
火绳枪：火药弹道学 + 弹速 +0.5/+0.2；堡垒：城堡/箭塔射速；凯尔特狂暴：攻城器生命。

单位 / 科技（中文名对齐 biligame）
-----------
资源：黄金、木材、食物、石料（四种；热键 z/x/Shift+Z/Shift+X）。
费用、时间与战斗属性：严格按帝国时代2决定版（SiegeEngineers aoe2techtree）。
主基地：城镇中心（town_center），不是 townhall。
建筑：城镇中心、兵营、靶场、马厩、铁匠铺、攻城武器厂、磨坊、采矿场、城堡、大学、修道院…
单位：民兵→剑士→…→冠军剑士；步弓手→弩手→劲弩手；长矛兵→长枪兵→长戟兵；
      轻型冲车、轻型/中型投石车、巨型投石机、游侠、甲胄骑兵 等。
铁匠铺：锻造/铸铁/鼓风炉、步兵甲、骑兵甲、箭羽/锥子箭/护腕、射手甲。
大学：弹道学用 ``projectile_lead``；飞行**速度**（格/秒，不是飞多久）用 ``rdg_projectile_speed`` / ``mdg_projectile_speed``（箭 7、投石车 3.5、投石机 1.6）。远程伤害前摇用 ``rdg_ready``（掷斧等近战投射物用 ``mdg_ready``），数值对齐 DE Attack Delay；``*_cd`` = RoF − 前摇。战船/塔/城防前摇为 0。命中率用 ``rdg_cover`` / ``mdg_cover``（0–100，省略=100%%），对齐 DE Accuracy；拇指环另加 ``rdg_cover`` 至满。
已禁用原版 fantasy 科技。

市场与贸易
----------
- 市场：买入/卖出木、粮、石（每批 100，货币黄金；默认约 30% 税，行会后约 15%）；有盟友时可进贡。
- 贸易马车：封建可训；对另一市场跑商赚黄金（路程够远才有收益）。
- 贸易船：船坞训；对码头/船坞跑商赚黄金。
- 机制由引擎通用参数驱动，详见仓库文档 ``doc/zh/mod/market-system.htm``、``doc/zh/player/market-and-trade.htm``（构建后）与发行说明 1.4.6.9。
