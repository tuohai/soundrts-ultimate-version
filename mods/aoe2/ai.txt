; ===========================================================================
; AoE2 DE-style AI — civilizations × difficulties
; Difficulties: beginner intermediate advanced expert nightmare
;
; Race start is DE Dark Age: 3 villagers + scout (Chinese 6 vils, 0 food).
; Difficulty gifts (all civs): no extra vils on beginner/intermediate/advanced;
; expert +1, nightmare +2. starting_resources is gold/wood/food/stone — food
; slot is always 0 so nobody gets free Dark Age food. First get is a villager
; TARGET so 3/6-vil starts still train more; workers >= later villager get.
;
; Age-staged get lines (not res-style mixed waves):
;   dark   = villagers only
;   feudal = militia + feudal trainables (archers / scouts / spears)
;   castle = knights / unique units + battering rams
;   siege  = more rams / mangonels (building-breakers)
; Unit names are real aoe2 rules types, not footman/archer/knight aliases.
; ===========================================================================
