;
; Real scenario facts reproduced here:
;   * Year 1087-1094. The player is SPANISH again -- the civilization
;     switches back from Saracens (ch. 3-4) to Spanish here.
;   * El Cid is in exile in the west and has no land of his own. He
;     crosses the Ebro, takes the coastal town of DENIA and holds it.
;   * Count BERENGUER of Barcelona (Franks) then attacks Denia with
;     trebuchets and bombard towers. El Cid cannot hold the town, so
;     he FLEES SOUTH across the river (this is the scenario's hinge:
;     you must not be trapped north of the Ebro).
;   * On the way south he passes LERIDA, whose knights and camel riders
;     change sides and join him, and the monastery of GAIA, whose monks
;     give him 2 Missionaries.
;   * He reaches VALENCIA on the Mediterranean coast. The Valencian
;     villagers begin building the WONDER.
;   * The chapter ends when the Wonder is finished. Berenguer's Frankish
;     army attacks Valencia throughout, so the Wonder must survive the
;     whole construction.
;

; Objective 4: El Cid reaches Valencia.  Reaching the city starts
; the construction of the WONDER, and the wonder is the thing that has
; to survive the siege, so it is spawned HERE and not at map start:
; the 10-minute countdown must begin at this moment.
;
; ``add_units`` puts the building in the PLAYER's hands (the trigger
; belongs to player1), so the wonder's own victory timer would hand
; the victory to the player when it runs out.  That is not used here:
; ``npc_wonder`` sets ``victory_time 0``, which cancels the inherited
; auto-victory countdown, and the chapter's own timer decides.
;
; Arrival also LATCHES the siege clock (``siege_started``).  The
; countdown used to be a plain ``(timer 15)`` trigger, which counts
; from the MAP START -- so the "10 minutes of siege" had already
; elapsed long before El Cid ever reached Valencia, and the chapter
; could be won without ever fighting the siege.
trigger player1 (timer 0) (set_var siege 0)
trigger player1 (timer 0) (set_var siege_started 0)
trigger player1 (has_entered k2 npc_cid_mounted) (do (objective_complete 4) (add_units k2 1 npc_wonder) (cut_scene 9264) (set_var siege 0) (set_var siege_started 1))

; Objective 5: hold Valencia until the Wonder is finished.
;
; The siege lasts 10 minutes of GAME time (600 s) counted from the
; moment El Cid enters Valencia (k2), not from the map start.
;
; ``(timer N)`` counts from the map start and cannot be re-anchored,
; so the countdown is driven by a TICK COUNTER instead: a repeatable
; trigger with a 20-second cooldown adds 1 to ``siege`` every 20 s
; while ``siege_started`` is latched.  The counter is reset to 0 by
; the arrival trigger, so tick k corresponds to k * 20 s after the
; arrival:
;
;   siege = 1 + floor(elapsed / 20 s)
;
; The original map-start timings are preserved as ratios of the
; 15-tick (600 s) siege:
;
;   (timer 10) -> 400 s -> siege 21 -> cut_scene 9265
;   (timer 13) -> 520 s -> siege 27 -> cut_scene 9266
;   (timer 14) -> 560 s -> siege 29 -> cut_scene 9267
;   (timer 15) -> 600 s -> siege 31 -> objective 5 + victory
;
; The announcements at 9265 / 9266 / 9267 make the wait legible --
; without them the player has no idea how long the siege still has to
; last.
trigger player1 repeat 20 (var siege_started >= 1) (add_var siege 1)
trigger player1 (var siege >= 21) (cut_scene 9265)
trigger player1 (var siege >= 27) (cut_scene 9266)
trigger player1 (var siege >= 29) (cut_scene 9267)
trigger player1 (var siege >= 31) (do (objective_complete 5) (victory))

; ---------------------------------------------------------------------------
; DEFEAT
;
; The Wonder is the whole point of the chapter: if it falls the city
; falls with it and the scenario is lost.
;
; The wonder only exists AFTER El Cid reaches Valencia (it is spawned
; by the objective-4 trigger), so the raw ``(building_lost npc_wonder)``
; condition would be TRUE from the very first tick -- the wonder is
; simply not there yet -- and the chapter would be lost in seconds.
; The condition is therefore gated on the siege clock, which is latched
; at the same moment the wonder appears.
trigger player1 (and (var siege_started >= 1) (building_lost npc_wonder)) (defeat)
trigger player1 (no_unit_left) (defeat)
trigger player1 (key_unit_killed npc_cid_mounted) (defeat)
