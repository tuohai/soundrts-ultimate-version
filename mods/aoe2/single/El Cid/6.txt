; Real scenario facts reproduced here:
;   * Year 1094-1102. The player is SPANISH and commands the garrison
;     of VALENCIA under XIMENA DÍAZ, El Cid's widow.
;   * El Cid is MORTALLY WOUNDED. His body is strapped to his horse
;     Babieca and set in front of the castle of Valencia, so that the
;     garrison does not learn that its lord is dead.
;   * If the body is harmed, the garrison loses heart and the scenario
;     is lost -- hence the ``(key_unit_killed npc_cid_body) (defeat)``
;     trigger below. The body is therefore a must-survive key unit.
;   * Three enemies attack at once:
;       - the BLACK GUARD ARMY in the north (Berenguer's Frankish
;         army, with trebuchets and bombard towers),
;       - the BLACK GUARD NAVY in the south-west (docks and war
;         galleys along the coast),
;       - YUSUF IBN TASHFIN, the Almoravid sultan, across the
;         Mediterranean in AFRICA (the southern shore).
;   * The player must defeat all three.
;

; ---------------------------------------------------------------------------
; OBJECTIVES
;
;   1 = Defeat the Black Guard Army in the north
;   2 = Destroy the four Black Guard docks in the south-west
;   3 = Defeat Yusuf ibn Tashfin across the sea
;
; All three are primary: the chapter ends when the whole Reconquista
; is done.
; ---------------------------------------------------------------------------
trigger player1 (timer 0) (register_objective 1 2 3)
trigger player1 (timer 0) (add_objective 1 9203)
trigger player1 (timer 0) (add_objective 2 9204)
trigger player1 (timer 0) (add_objective 3 9205)

; Objective 1: the Black Guard Army -- both of Berenguer's bases must
; fall.  As in ch. 4, the two one-shot triggers count the fallen
; bases in a variable and a repeatable trigger completes the objective
; once the counter reaches two.  Two separate triggers that each
; called ``(objective_complete 1)`` would complete the objective when
; the FIRST base fell.
trigger player1 (enemy_building_destroyed d7 aoe_castle) (add_var army 1)
trigger player1 (enemy_building_destroyed f7 town_center) (add_var army 1)
trigger player1 repeat (var army >= 2) (do (objective_complete 1) (cut_scene 9268))

; Objective 2: all four Black Guard docks are destroyed.
trigger player1 (enemy_building_destroyed b1 shipyard) (add_var docks 1)
trigger player1 (enemy_building_destroyed d1 shipyard) (add_var docks 1)
trigger player1 (enemy_building_destroyed g1 shipyard) (add_var docks 1)
trigger player1 (enemy_building_destroyed j1 shipyard) (add_var docks 1)
trigger player1 repeat (var docks >= 4) (do (objective_complete 2) (cut_scene 9269))

; Objective 3: Yusuf's fortress in Africa falls.
;
; NOTE: this must NOT be ``(no_enemy_player_left)``.  That condition only
; counts players that take part in the match (human players and invited
; computer opponents).  Every campaign NPC here is a ``computer_only``
; slot whose ``broadcasts_defeat_and_quit`` is False, so
; ``no_enemy_player_left`` is already True on the very first tick --
; the chapter would end instantly.
trigger player1 (enemy_building_destroyed l2 aoe_castle) (do (objective_complete 3) (cut_scene 9270) (victory))

; ---------------------------------------------------------------------------
; DEFEAT
;
; The body of El Cid must not be harmed -- that is the whole point of
; the scenario.  Losing it loses the chapter.
; ---------------------------------------------------------------------------
trigger player1 (no_unit_left) (defeat)
trigger player1 (key_unit_killed npc_cid_body) (defeat)
trigger player1 (key_unit_killed npc_ximena) (defeat)
