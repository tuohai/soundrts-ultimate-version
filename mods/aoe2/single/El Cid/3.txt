; El Cid starts ALONE -- that is the whole point of the exile. He has
; no army, no villagers and no buildings until he wins the Allies.
;
; Starting resources (600 wood / 500 gold / 400 food / 400 stone):
; a Town Center costs 275 wood + 100 stone, so the player CAN build one
; immediately -- which is the whole point: without a Town Center the
; villagers cannot deposit anything (only ``town_center`` stores all
; four resource types; ``workshop`` and ``aoe_castle`` store NOTHING),
; no ``mining_camp`` / ``lumbermill`` / ``mill`` / ``barracks`` can be
; raised (they all have ``requirements town_center``), and the ages
; cannot be advanced (only the Town Center can ``can_advance``).
;
; Age chain: ``dark_age`` / ``feudal_age`` / ``castle_age`` must ALL be
; listed, even though the chapter starts in the castle age:
;   * ``Player.has()`` looks the name up in ``player.upgrades``, so
;     ``requirements castle_age`` (workshop, battering_ram, mangonel)
;     is satisfied directly;
;   * ``castle_age`` itself requires ``feudal_age``, which is checked
;     by literal name, so ``feudal_age`` must be listed too.
; The DE original's chapter 3 is a Castle Age scenario -- El Cid is
; exiled with a Moorish army and besieges castles.

; The ``story`` semantic tier covers "easy" and "standard" (easy is the

;

; Objectives
;   1 = Mount Babieca (take over the mounted El Cid at the stable)
;      AND take the four Camel Riders
;   2 = Join Motamid in Zaragoza
;   3 = Destroy Berenguer's Siege Workshop
;   4 = Defeat Count Berenguer
;   1 (optional) = Destroy Alfonso's Castle
;
; Numbering rule of this engine: ``register_objective`` lists the
; PRIMARY objectives that must all be completed for the mission to
; end, and ``add_secondary_objective`` numbers live in a separate
; key space (Objective.storage_key with optional=True).  A secondary
; objective therefore must NOT appear in ``register_objective``, and
; a primary objective number must be completed with
; ``objective_complete`` (not ``secondary_objective_complete``) --
; only the primary completion adds the number to
; ``_completed_objective_numbers``, which is what ``_try_mission_victory``
; checks.
;
; So: primary objectives are 1, 2, 3, 4 (1 = mount up, 2 = Zaragoza,
; 3 = the siege workshop, 4 = Berenguer).  The optional one is the
; only optional objective of the chapter, so it is "optional
; objective 1".
;
; The two numbering spaces are INDEPENDENT and both start at 1 (see
; doc_src/src/*/mod/mapproduction): primary objectives run 1..N, and
; optional objectives run 1..M in their own space.  An optional
; objective therefore never takes up a primary number -- numbering
; the optional one 5 (as this chapter used to) both skipped the
; primary number 2 and made the list read "optional objective 5",
; while the primary list jumped from "objective 1" to "objective 3".
;
; The TTS ids are independent of the objective numbers: 9187 = mount
; up, 9189 = Zaragoza, 9190 = the siege workshop, 9191 = Berenguer,
; 9188 = Alfonso's Castle (the optional one).
trigger player1 (timer 0) (register_objective 1 2 3 4)
trigger player1 (timer 0) (add_objective 1 9187)
trigger player1 (timer 0) (add_objective 2 9189)
trigger player1 (timer 0) (add_objective 3 9190)
trigger player1 (timer 0) (add_objective 4 9191)
trigger player1 (timer 0) (add_secondary_objective 1 9188)

; Objective 1 has TWO halves: El Cid must MOUNT Babieca at the stable
; (c1) AND take the four Camel Riders (d2).  The objective text
; (tts 9187, "Mount Babieca and take the camel riders") promises both,
; so it may only be completed once BOTH are done.  Each of the two
; triggers below therefore checks whether the other half is already
; fulfilled -- whichever of the two the player does LAST completes
; objective 1.
;
; Mounting Babieca: the MOUNTED hero (npc_cid_mounted, "El Cid
; Campeador" -- El Cid already sitting on Babieca) waits at the stable
; (c1).  When the on-foot Cid reaches it, that mounted unit is handed
; over to the player and the on-foot copy is deleted -- that is how the
; DE campaign swaps the two.  Deleting (rather than killing) the on-foot
; hero is deliberate: ``key_unit_killed npc_cid`` is a defeat
; condition, and Alfonso's watchtowers shoot at everything standing
; near the gate, so a leftover second El Cid would eventually lose the
; chapter.
;
; NOTE: every ``has_entered`` trigger below must accept BOTH
; ``npc_cid`` and ``npc_cid_mounted``.  ``has_entered`` matches a unit
; by exact type name or by its ``is_a`` chain, and ``npc_cid_mounted``
; is ``is_a knight`` -- so a trigger naming only ``npc_cid`` would
; never fire again once the hero is mounted.
trigger player1 (has_entered c1 npc_cid) (do (cut_scene 9254) (transfer_units computer1 player1 c1 1 npc_cid_mounted) (remove_ground_item c1 npc_cid) (if (has 4 camel_rider) (do (objective_complete 1))))

; The four Camel Riders join the player when El Cid reaches them; if
; he is already mounted, this completes objective 1.
trigger player1 (has_entered d2 npc_cid npc_cid_mounted) (do (transfer_units computer3 player1) (cut_scene 9255) (if (has 1 npc_cid_mounted) (do (objective_complete 1))))

; The windmill garrison (c6): 2 knights and 6 pikemen who change sides.
;
; DE original: the garrison of the windmill that El Cid passes on his
; way north defects to him as soon as he reaches it.  This chapter used
; to leave them in the windmill forever -- the player never got them,
; so the whole northern half of the map was fought with nothing but
; the four camel riders and the two knights at the stable.
;
; ``transfer_units`` changes ownership of the existing units (it does
; NOT spawn copies), so the windmill is emptied exactly once.
trigger player1 (has_entered c6 npc_cid npc_cid_mounted) (do (transfer_units computer2 player1))

; Optional objective 1 (SECONDARY, as in the DE original): Alfonso's
; Castle falls.  It is optional -- the road to Zaragoza is opened by
; the GATA camp's siege workshop, so the player may go around it.
trigger player1 (enemy_building_destroyed f4 aoe_castle) (do (secondary_objective_complete 1) (cut_scene 9256) (alliance 1 computer7))

; The GATA camp (f2): the player takes the Gaia base -- the Town Center,
; the Siege Workshop, the villagers and the siege train -- plus the
; resources it carries.
;
; This is where the player gets an economy.  Before this the player is
; alone with a horse and four camel riders, so the optional objective
; (Alfonso's Castle: 4800 HP + 2 watchtowers + 4 pikemen + 2 knights)
; is simply not winnable.
trigger player1 (has_entered f2 npc_cid npc_cid_mounted) (do (transfer_units computer8 player1) (grant_resources 500 resource1 800 resource2 500 resource3 300 resource4))

; Objective 2: Motamid in Zaragoza -- the player joins him.
;
; ``npc_cid_mounted`` has to be listed next to ``npc_cid``: by the time
; the player gets here the hero is already mounted, and a trigger
; naming only ``npc_cid`` would never fire.
;
; Motamid's castle (h6) joins the player as well: in the DE original
; Zaragoza is the base the player builds his army in.  ``aoe_castle``
; is not a warehouse (``storable_resource_types`` is empty), so it
; gives no economy -- the Town Center from the GATA camp does that.
trigger player1 (has_entered h6 npc_cid npc_cid_mounted) (do (objective_complete 2) (cut_scene 9257) (transfer_units computer9 player1))

; Objective 3: Berenguer's Siege Workshop is destroyed, which is what
; opens the road to his fortress.
;
; The reward is the DE original's reward: the troops AND the buildings
; that were inside Zaragoza's walls -- a Town Center, peasants, knights
; and Berenguer's own camel riders, who now defect to the Cid.  These
; are NOT the four Camel Riders of objective 1 (those wait in the
; south-west valley at d2); handing out a second batch of camel riders
; here is what used to make objective 1 look like it had been given
; already.
;
; The Town Center matters: it is the only building that can store all
; four resource types, and every economy building requires one, so
; without it the peasants handed over here cannot mine, cannot build
; and cannot deposit anything.  It goes to h5, the square the workshop
; was defending.
trigger player1 (enemy_building_destroyed h4 workshop) (do (objective_complete 3) (add_units h5 1 town_center 6 peasant 4 aoe_knight 2 camel_rider 1 mangonel 1 battering_ram) (grant_resources 500 resource1 500 resource2 400 resource3 300 resource4))

; Objective 4: Count Berenguer himself falls.
;
; NOTE: this must NOT be ``(no_enemy_player_left)``.  That condition only
; counts players that take part in the match (human players and invited
; computer opponents).  Every campaign NPC here is a ``computer_only``
; slot whose ``broadcasts_defeat_and_quit`` is False, so
; ``no_enemy_player_left`` is already True on the very first tick -- the
; chapter would end instantly.  ``(enemy_building_destroyed i2
; aoe_castle)`` is the honest condition: Berenguer's fortress is his
; seat, and it falls when he does.
trigger player1 (enemy_building_destroyed i2 aoe_castle) (do (objective_complete 4) (victory))
