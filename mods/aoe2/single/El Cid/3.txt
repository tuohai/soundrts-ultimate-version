; Objectives
;   1 = Mount Babieca and take the four Camel Riders
;   2 = Destroy Alfonso's Castle (SECONDARY in the DE original)
;   3 = Join Motamid in Zaragoza
;   4 = Destroy Berenguer's Siege Workshop
;   5 = Defeat Count Berenguer
;
; Numbering rule of this engine: ``register_objective`` lists the
; PRIMARY objectives that must all be completed for the mission to
; end, and ``add_secondary_objective`` numbers live in a separate
; key space (Objective.storage_key with optional=True).  A secondary
; objective therefore must NOT appear in ``register_objective``, and
; a primary objective number must be completed with
; ``objective_complete`` (not ``secondary_objective_complete``) --
; only the primary completion adds the number to
; ``_completed_objective_numbers``, which is what ``_try_mission_victory``
; checks.
;
; So: primary objectives are 1, 3, 4, 5 (1 = mount up, 3 = Zaragoza,
; 4 = the siege workshop, 5 = Berenguer).  The optional one is 2.
trigger player1 (timer 0) (register_objective 1 3 4 5)
trigger player1 (timer 0) (add_objective 1 9187)
trigger player1 (timer 0) (add_secondary_objective 2 9188)
trigger player1 (timer 0) (add_objective 3 9189)
trigger player1 (timer 0) (add_objective 4 9190)
trigger player1 (timer 0) (add_objective 5 9191)

; Objective 1: El Cid reaches Babieca's stable and mounts up.
trigger player1 (has_entered c1 npc_cid) (do (objective_complete 1) (cut_scene 9254))

; The four Camel Riders join the player when El Cid reaches them.

; Objective 2 (SECONDARY, as in the DE original): Alfonso's Castle
; falls.  It is optional -- the road to Zaragoza is opened by the
; GATA camp's siege workshop, so the player may go around it.
trigger player1 (enemy_building_destroyed f4 aoe_castle) (do (secondary_objective_complete 2) (cut_scene 9256) (alliance 1 computer7))

; Objective 3: Motamid in Zaragoza -- the player joins him.
trigger player1 (has_entered h6 npc_cid) (do (objective_complete 3) (cut_scene 9257))

; Objective 4: Berenguer's Siege Workshop is destroyed, which is what
; opens the road to his fortress.
trigger player1 (enemy_building_destroyed h4 workshop) (do (objective_complete 4) (add_units h5 4 peasant 2 aoe_knight 2 camel_rider))

; Objective 5: Count Berenguer himself falls.
;
; NOTE: this must NOT be ``(no_enemy_player_left)``.  That condition only
; counts players that take part in the match (human players and invited
; computer opponents).  Every campaign NPC here is a ``computer_only``
; slot whose ``broadcasts_defeat_and_quit`` is False, so
; ``no_enemy_player_left`` is already True on the very first tick -- the
; chapter would end instantly.  ``(enemy_building_destroyed i2
; aoe_castle)`` is the honest condition: Berenguer's fortress is his
; seat, and it falls when he does.
trigger player1 (enemy_building_destroyed i2 aoe_castle) (do (objective_complete 5) (victory))

; Defeat conditions.
