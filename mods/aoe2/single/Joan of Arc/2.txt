; 2 — The Maid of Orleans (AoE2 DE Joan of Arc, ch. 2)
;
; Faithful rewrite of AoE2 DE ch. 2 "The Maid of Orleans".  Source
; walkthroughs (ageofempires.fandom.com/wiki/The_Maid_of_Orleans,
; standardof.net, aok.heavengames.com) describe this chapter as a
; long, two-phase mission: first a small escort reaches Blois to
; pick up the French army + 6 Trade Carts, then Joan + the carts
; are ferried across the Loire by 2 Transport Ships to the city of
; Orleans, where Orleans hands over its town + villagers to the
; player.  After that the player builds up to Castle Age (population
; cap 125, Imperial forbidden) and must destroy 1 of the 2 English
; Castles.  Joan and the cathedral in Orleans must survive.
;
; Map grid (12x8):
;   [a1..a8] is the south-west corner (Chinon, starting position);
;   column e is the Blois camp (large neutral French army, trade carts);
;   column f is the south English keep (just across the river from Blois);
;   row 4 is the Loire (terrain river; the bridge is at f4, with a
;   Burgundian guard tower on the south side at f3);
;   column h is Orleans (town_center, cathedral, several allied French
;   militia/archer defenders) — handed to the player on completion of
;   objective 3;
;   column k is the north English keep (the Castle the player must
;   destroy to complete objective 4);
;   column l is the outer English fortification (the other Castle, kept
;   to make the map feel like a siege ring).

; --- Vaucouleurs / Chinon (player start, a1) -----------------------------
; Faithful to AoE2 DE ch. 2 starting force:
;   - 1 Joan of Arc (npc_joan, hero unit, MUST survive)
;   - 1 Duke d'Alençon (npc_d_alencon, second hero, can fight)

; combat hero who can fight but is not a key unit.

; STARTING TOWN CENTER (2026-11-21 fix -- user-reported: "Objective 3
; cannot be completed, there is no Town Center").
;
; The player used to start with NO building at all.  Only ``town_center``
; and ``townhall`` declare ``can_advance feudal_age castle_age
; imperial_age`` in mods/aoe2/rules.txt, so with no Town Center the
; player had:
;   * no ``can_advance`` menu entry  -> the "Advance to Feudal Age"
;     button literally did not exist in the UI;
;   * no warehouse                    -> the 4 starting peasants had
;     nowhere to deposit what they gathered;
;   * no build menu                   -> no house, no mill, no farm.
;
; Objective 3 ("advance to Castle Age") was therefore *unreachable by
; construction*: the only Town Center on the map was the Orleans one,
; which the player only receives after completing objective 2 (the
; Blois -> Orleans trade-cart escort, ~15 squares of walking).  By the
; time the player owned a Town Center they had to ALSO have gathered
; 500 food for Feudal + 800 food and 200 gold for Castle, from a map
; whose entire food supply was a single finite 200-food orchard.
;
; So Chinon now starts as a real (small) French town, exactly like the
; other Joan chapters (1.txt / 3.txt / 4.txt / 5.txt all start with a
; ``town_center``).  This does NOT skip any objective: the DE chapter
; still opens at Chinon with Joan and the escort, the Blois hand-over
; and the Orleans hand-over are unchanged, and the chapter is still
; capped at Castle Age.
;
; The numbers below are deliberately generous but not absurd:
;   * town_center : 275W 100S -> provides 5 pop, stores ALL 4 resources
;     (it is the drop-off the peasants need), and carries the
;     ``can_advance`` menu that objective 3 needs.
;   * 4 peasant    : the working force (Chinon is a village).
;   * 4 house      : 4 x 5 = 20 pop headroom.  Without houses the
;     player starts with population supply 0 against 19 used, so EVERY
;     train order is refused with "not_enough_population" -- the player
;     could not even replace a lost peasant, let alone grow an economy.
;   * mill + 3 farm (on b1, next to Chinon): the food economy.  The
;     map's finite food is ``orchard 200 a1`` + ``orchard 300 g6`` +
;     ``orchard 300 h5`` = 800 food, but the age-up needs 500 (Feudal)
;     + 800 (Castle) = 1300 food, and 4 peasants cannot gather 800
;     food in time.  The mill is the food drop-off
;     (``storable_resource_types resource3``) and each farm is 175 food
;     that REPLANTS ITSELF for 60 wood (``auto_cultivate`` in
;     mods/aoe2/rules.txt + the engine's
;     ``_auto_enable_farm_cultivation``), so the food supply is
;     renewable instead of finite.
;   * 300G 300W 1000F 150S : the DE chapter gives the player a
;     starting purse; 1000 food covers Feudal (500) plus most of
;     Castle (800), so the age-up chain is never a resource race.
;     The 300 wood / 150 stone also cover the two Feudal buildings the
;     Castle Age gate demands (see the "CASTLE AGE GATE" note below).
;
; population math (see worldplayerbase/base.py: ``population`` is the
; SUPPLY from buildings, ``used_population`` is the cost of units):
;   supply = town_center 5 + 4 houses 20            = 25
;   used   = joan 1 + alencon 1 + scout 1 + 2 swords 2
;            + 4 knights 8 + 6 carts 6 + 4 peasants 4 = 23
;   headroom = +2 -> the player can train a 5th peasant.
;
; CASTLE AGE GATE (why the map hands the player a market):
;   mods/aoe2/rules.txt declares
;       def castle_age
;       requirements feudal_age any_buildings 2 feudal_age_buildings
;   and ``feudal_age_buildings`` resolves to
;       archery_range, blacksmith, gate, market, scouttower, stables, wall
;   so the player must own TWO DIFFERENT buildings from that list.
;   The Orleans hand-over gives them the ``scouttower`` (h7) and the
;   ``market`` (h7) -- exactly two, as in the AoE2 DE chapter, where the
;   city of Orleans already stands with its market.

; --- Blois (e2+e3) --------------------------------------------------------
; The French army + trade carts await Joan here.  When Joan reaches Blois
; the (add_units) trigger below moves the army to the player.  The camp
; itself stays as Gaia decoration so the minimap shows a French base.
; IMPORTANT: do NOT pack all of these into a single 8x8 cell.
; soundrts' square_capacity is the map's ``square_width`` (12) expressed in

; the exits (see CHANGELOG_AUDIT / soundrts/worldroom.py).  Split the
; camp across e2+e3 (the decoration), and the (add_units) trigger

; ``trigger computerN`` binds to the N-th ``computer_only`` line of this
; file, in file order.  Blois used to be split over THREE lines (e2, e3
; units, e3 monastery), which pushed every later slot one past the base
; it was meant to be: the Orleans h7 garrison got the English "alliance 2"
; (and attacked the player), Burgundy f3 got "alliance 1" (and never
; attacked), the Blois monastery got "alliance 2", and the l6 outwork was
; left on the default "ai" alliance.  The e3 units and the e3 monastery

;
;   slot 1 = Blois e2      slot 2 = Blois e3      slot 3 = Burgundy f3
;   slot 4 = Orleans h6    slot 5 = Orleans h7    slot 6 = English k5
;   slot 7 = English k6    slot 8 = English l5    slot 9 = English l6

;
;     On Standard, all four English bases are missing a Guard Tower each,

trigger player1 (and (has_entered h6 npc_joan) (has 6 trade_cart) (has_entered h6 trade_cart)) (do (cut_scene 8836) (transfer_units orleans_h6 player1) (transfer_units orleans_h7 player1) (objective_complete 2))

; --- Objective 3: Reach Castle Age ----------------------------------------
; Once the player has dark_age + feudal_age + castle_age in upgrades,
; objective 3 is complete.  Imperial Age is FORBIDDEN via the "-imperial_age"
; entry on the player line above (so the chapter is capped at Castle Age,
; population 125, matching AoE2 DE ch. 2).
trigger player1 (and (has castle_age) (not (has imperial_age))) (objective_complete 3)

; --- Objective 4: Destroy 1 English Castle -------------------------------
; AoE2 DE ch. 2: "Convince the British to withdraw by destroying 1 of
; their Castles."  Either English Castle counts (k5 or l5).
;
; IMPORTANT: ``enemy_building_destroyed`` means "there is no *enemy* castle
; of this type on that square any more".  It therefore also becomes true
; when the castle merely CHANGES OWNER (hand-over / capture) -- it is no
; longer an enemy building, but it was not destroyed either.  That is
; exactly how this objective used to fire for free right after objective 2.
; So the condition is strengthened with ``killed_target ... enemy``: the
; castle must have been actually DESTROYED by the player (or their team).
;
; ``killed_target <square> <index> <type> enemy`` is keyed on the map
; spawn index of the castle on that square (both English castles are the
; 1st aoe_castle on their square).
trigger player1 (or (and (enemy_building_destroyed k5 aoe_castle) (killed_target k5 1 aoe_castle enemy)) (and (enemy_building_destroyed l5 aoe_castle) (killed_target l5 1 aoe_castle enemy))) (do (cut_scene 8838) (objective_complete 4))

; --- Defeat conditions ----------------------------------------------------
; Joan must survive (key unit).  The cathedral in Orleans (npc_cathedral)
; must survive (DE ch. 2 explicit victory condition).  All 6 trade_carts
; must survive (DE ch. 2 explicit; trade_cart death is a soft fail).
trigger player1 (key_unit_killed npc_joan) (defeat)
trigger player1 (key_unit_killed npc_cathedral) (defeat)
trigger player1 (no_unit_left) (defeat)

; Auto-defeat computers whose last unit dies (so the campaign map's
; "Joan victorious" hero portrait doesn't get stuck on Blois/Orleans).
trigger all (no_unit_left) (defeat)

; Trade-cart protection: the player MUST still have 6 trade_carts alive
; 10 minutes (600 game seconds) after the start of the chapter.
;
; NOTE: ``timer N`` counts N *timer_coefficient* GAME SECONDS, and this
; map sets ``timer_coefficient 40`` (so one map "timer unit" is 40
; game seconds).  The old ``(timer 600)`` therefore fired after
; 600*40 = 24000 s = 400 minutes -- the deadline was effectively dead
; code.  15 * 40 = 600 s = 10 minutes, which is the intended deadline.
trigger player1 (and (timer 15) (lt (count trade_cart) 6)) (defeat)
