; 6 — A Perfect Martyr (AoE2 DE Joan of Arc, ch. 6)
;
; Story beats (DE Joan of Arc ch. 6 — defender POV):
;   Joan's stand at the Compiegne bridge in ch. 4 has given the
;   Burgundians/English a strategic opening.  They lay siege to
;   the citadel of Compiegne, where the French garrison still
;   holds under Dunois.  The perfect stratagem is the encirclement
;   that ends Joan's campaign.  Here the PLAYER defends: hold
;   Compiegne until Charles VII is crowned at Reims, then escort
;   Joan across the Oise bridge to safety.
;
; Ch. 6 is a pure DEFENCE mission:
;   * The player is the FRENCH garrison (faction franks) at the
;     Compiegne citadel (e6) -- NOT the Burgundian besieger.  The
;     previous version of this file put the player in the Burgundian
;     besieger's shoes while the objective text said "hold
;     Compiegne" -- the two could never agree.
;   * Charles VII's coronation is a COUNTDOWN: it happens 12 timer
;     ticks into the battle (6 real minutes at
;     timer_coefficient 30), and the player wins by still holding the
;     citadel when the crown lands.
;   * The English and Burgundian besiegers DO attack.  A
;     ``computer_only`` slot defaults to a trigger-only do-nothing AI
;     (see doc_src/src/en/mod/mapmaking.rst "Switch to another AI"),
;     so every attacker here is explicitly given ``(ai
;     intermediate)``.
;
; Map grid (10x8, the Oise river along row 4):
;   [a8] [b8] [c8] [d8] [e8] [f8] [g8] [h8] [i8] [j8]   <- north bank, French side
;   [a7] ...                                      [j7]
;   [a6] ...                                      [j6]   <- Compiegne citadel at e6
;   [a5] ...                                      [j5]
;   [a4] ...                                      [j4]   <- Oise river row
;   [a3] ...                                      [j3]   <- south bank, besiegers
;   [a2] ...                                      [j2]
;   [a1] ...                                      [j1]
;
;   Player base:   Compiegne citadel (e6) -- French, with the citadel
;                  castle, Joan and the Dauphin.
;
;   FOUR CROSSINGS -- this is the whole point of the chapter.  The Oise
;   is crossed at b4 (ford), e4 (stone bridge), g4 (ford) and i4
;   (ford).  Besiegers on the south bank therefore have to SPLIT their
;   army: they can no longer all funnel onto one bridge.
;
;   Why this matters (the bug this fixes):  with a single crossing the
;   only land route into the citadel was e5 -> e6, so one stack parked
;   on e5 sealed the map and the defence was trivially easy -- the
;   besiegers reached e5 and never touched e6.  Measured with
;   _tools/probe_ch6_routes.py before the change:
;       crossings(row4) = ['e4']   near citadel = ['e5']
;   With the fords the attacker has to commit to a crossing and then
;   cross open ground, so the garrison can be split between the bridge
;   and the fords instead of all sitting on one tile.
;
;   The fords are deliberately SLOW (``ford`` terrain is ``speed .5 1``:
;   half speed for ground units), so they are chokepoints the player's
;   archers can shoot into, not free highways.  The stone bridge at e4
;   stays the fast route and the only one Joan escapes over in the
;   epilogue.
;
;   Besiegers:     English siege ring on the south bank (c2) plus
;                  a Burgundian camp (h1) and a British outpost
;                  covering the western approach (a1).

; The Oise is row 4.  south_north_paths must SKIP row 4 for every
; column except the bridge column e -- otherwise the water squares
; become vertical passages and the besiegers can walk across the
; river anywhere.  (ch2 uses the same rule for the Loire: only f4
; appears in a south_north line.)
;
; EXCEPTION -- the FORD columns b, g and i.  Those river squares are
; ``terrain ford``: water for the river's continuity, but also
; walkable ground (is_water 1 + is_ground 1), exactly like the

; The Oise river: row 4.  e4 is the stone bridge -- it is water for
; the river's continuity AND ground the player can walk on, exactly the
; pattern ch2 uses for the Loire at f4.
;
; b4 / g4 / i4 are the shallow FORDS.  The ``ford`` terrain in
; mods/aoe2/rules.txt is ``is_water 1`` + ``is_ground 1`` + ``speed .5 1``:
; ground units may cross it, but at HALF speed, so every ford is a
; chokepoint the player's archers can shoot into rather than a
; free highway.  Four crossings (b4 ford, e4 bridge, g4 ford, i4 ford)
; is what forces the besiegers to split their army into several
; attacks instead of queueing on one bridge.

; ---------------------------------------------------------------------------
; The French garrison (PLAYER) -- defender at the Compiegne citadel.

; Age chain: must include dark_age and feudal_age even though the

; English siege ring on the south bank (computer1) -- the main
; besieger.  It gets a real AI so it actually attacks the citadel.
;
; The four leading numbers of a ``computer_only`` line are the
; starting resources (gold, wood, food, stone).  They MUST be
; non-zero: an AI with zero resources cannot train a single unit, so
; its ``get`` lines never complete and it sits still -- the AI would
; never attack.
;
; The trailing ``dark_age feudal_age castle_age`` are the starting
; age chain: without them the AI stays in the dark age and cannot
; build the feudal/castle units the attack waves are made of.
;
; The besiegers also need a FARM and production buildings:
; ``britons_intermediate`` in mods/aoe2/ai.txt has the get-lines
;
;     get 4 militia 8 aoe_archer
;     get 14 peasant 8 aoe_knight 8 longbowman 3 battering_ram
;
; and the second one needs FOOD.  Without a farm the besiegers burn
; through their starting food during the first wave, hit food = 0
; and then stall on the get-line forever -- they attack once and
; then sit there, which makes the defence trivial again.
;
; ``barracks`` / ``archery_range`` / ``stables`` give the AI the
; buildings its get-lines train from; ``farm`` keeps the food coming.
; ``battering_ram`` and ``mangonel`` need a ``workshop``, so the
; siege train needs one too (without it the AI cannot build the
; rams its plan asks for and stalls again).
computer_only 400 400 700 200 non_neutral faction britons c2 town_center 2 house farm 2 barracks archery_range stables workshop aoe_castle scouttower 5 militia 3 man_at_arms 2 aoe_archer 2 aoe_knight 1 longbowman 2 peasant 10 dark_age feudal_age castle_age

; ---------------------------------------------------------------------------
; MAKE THE BESIEGERS ACTUALLY ATTACK.
;
; A ``computer_only`` slot gets a trigger-only, do-nothing AI by default
; (doc_src/src/en/mod/mapmaking.rst "Switch to another AI"), so without
; this the besiegers would sit still and the defence would be a joke --
; exactly the bug reported for this chapter.
;
; ``(ai intermediate)`` swaps in mods/aoe2/ai.txt's
; ``britons_intermediate`` / ``burgundians_intermediate`` scripts, which
; contain real ``attack`` lines and ``attack_ratio 120`` -- they build
; an army and go at the citadel.
;
; NOTE the numbering: the ``computer_only`` lines above are computers
; 1, 2 and 3 (NOT 2, 3, 4) -- the first ``computer_only`` line becomes
; computer1.  computer1 is the English ring, computer2 the Burgundian
; camp, computer3 the western outpost beside the b4 ford.  ALL THREE
; get a real AI, so the siege comes at the citadel from the west
; (over b4), the centre (over the e4 bridge) and the east (over g4)
; at the same time.  A passive outpost would leave one crossing
; unpressured and the siege would still funnel through e5.
; ---------------------------------------------------------------------------
trigger computer1 (timer 0) (ai intermediate)
trigger computer2 (timer 0) (ai intermediate)
trigger computer3 (timer 0) (ai intermediate)

; ---------------------------------------------------------------------------
; THE CORONATION COUNTDOWN
;
; (timer 12) is a ONE-SHOT trigger: the engine removes a trigger once
; its condition has fired.  So this is a single event, not a
; repeating one.
;
; The coronation sets the ``crowned`` flag and completes objective 1.
; It does NOT end the chapter: the epilogue (escorting Joan over the
; bridge) is the actual ending.
;
; The citadel must still stand for the coronation to mean anything;
; if it fell earlier, the ``building_lost`` trigger already fired
; defeat and the game is over before this trigger ever runs.
;
; The intermediate announcements (timer 6 / 9 / 11) make the wait
; legible: without them the player has no idea how long the siege
; has to last.  Each one is a separate one-shot trigger, so they
; fire once each and are then removed by the engine.
; ---------------------------------------------------------------------------
trigger player1 (timer 6) (cut_scene 8897)
trigger player1 (timer 9) (cut_scene 8898)
trigger player1 (timer 11) (cut_scene 8899)
trigger player1 (timer 12) (do (set_var crowned 1) (objective_complete 1) (cut_scene 8895))

; ---------------------------------------------------------------------------
; THE EPILOGUE: JOAN ESCAPES OVER THE BRIDGE
;
; Objective 2 requires BOTH the coronation to have happened AND Joan
; to be standing on the bridge square e4.  It is a repeating trigger
; (the ``repeat`` modifier keeps it alive instead of removing it
; after the first fire), so the player can reach the bridge at any
; point after the coronation.
;
; If the player dawdles and the Dauphin dies, the key_unit_killed
; trigger ends the chapter in defeat -- that is the intended tension.
; ---------------------------------------------------------------------------
trigger player1 repeat (and (var crowned) (has_entered e4 npc_joan)) (do (objective_complete 2) (cut_scene 8896) (victory))

; ---------------------------------------------------------------------------
; VICTORY / DEFEAT
;
; Defeat: the citadel falls, or either hero is killed.
; ---------------------------------------------------------------------------
trigger player1 (building_lost town_center) (defeat)
trigger player1 (key_unit_killed npc_joan) (defeat)
trigger player1 (key_unit_killed npc_dauphin) (defeat)
trigger player1 (no_unit_left) (defeat)
