; 3 — The Maid's Last Stand (Orleans relief finale, Octave Day)
;   In AoE2 DE, this content is the tail of ch. 2 ("The Maid of Orleans")
;   rather than ch. 3 ("The Rising Sun" = Meung-sur-Loire / Beaugency,
;   which is covered in our ch. 5). The forts here are the two strongholds
;   that still hold the approaches to Orleans on the day after Joan enters
;   the city: St. Loup on the south bank and Les Tourelles on the north
;   bank across the bridge.
;
; Story beats:
;   The second day of the Orleans relief. Two English forts still
;   command the approaches: the Fort of St. Loup on the south bank
;   (a stone monastery converted into a bastion) and the outer
;   fortress of Les Tourelles on the north bank across the bridge.
;   Joan must storm both to break the siege.
;
; Map grid (8x6, with the Loire in row 3):
;   column a-b  : west bank / left flank (English reinforcements)
;   column c-d  : Orleans citadel (player base, d4 — north shore)
;   column e-f  : bridge corridor (Les Tourelles at f5)
;   column g    : east flank (English siege camp + lumber)
;
;   row 5 : Les Tourelles (f5) + outer English wall (g5)
;   row 4 : north shore / Orleans (player base at d4)
;   row 3 : LOIRE RIVER (a3..g3); bridge at d3 connects north to south
;   row 2 : south bank shore (a2-b2 + c2-d2 bridge head + e2-g2)
;   row 1 : south bank (Fort St. Loup at a1)
;
;   NB: nb_lines is 6 (grid rows 1-5) so that the bottommost
;   in-grid row 5 (1-based y = 5) is strictly LESS than
;   nb_lines (6) and does not trigger the engine's silent portal
;   wrap.  Same trick as Ch.2 (which uses rows 1-3 + 5-7 for an
;   8-line grid; row 4 is the river, row 8 is the wrap).
;
;   Player base: Orleans citadel at d4 (same coordinates as Ch.2's
;   intent, just one column in from where Ch.2 places Orleans at h6).
;   St. Loup: a1 (south bank, monastery)
;   Les Tourelles: f5 (north bank, castle + bridge)
;   Bridge: d3 (the only land crossing over the Loire)
;   English navy: e3 (longboat — closest in-game ship unit to a
;                 demolition_ship / cog since rules.txt has no cog/demoship)
;   English east camp: g5 (small garrison so the player can't just
;                      ignore the eastern flank)
;   English west camp: b5 (cavalry reinforcements, north of river)
;   English lumber camp: g2 (a few longbowmen holding the forest)
