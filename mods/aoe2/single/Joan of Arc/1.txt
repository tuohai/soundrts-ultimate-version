; 1 -- Uneasy Allies (AoE2 DE Joan of Arc, ch. 1)
;
; Story beats (DE Joan of Arc ch. 1):
;   Joan arrives at Vaucouleurs (west) and convinces Robert de
;   Baudricourt to grant her a small escort and a holy letter.
;   She then travels across English-held country to the Dauphin's
;   court at Chinon (east). Joan must survive the journey -- if
;   she dies, the war is lost.
;
; Map grid (7x4 -- a..g columns, 4 rows):
;       a       b       c       d       e       f       g   (g is buffer)
;    4 [a4] [b4=Baud.] [c4] [d4] [e4] [f4=Dau.] [g4]
;    3 [a3] [b3]   [c3] [d3=E] [e3=E] [f3]   [g3]
;    2 [a2] [b2]   [c2=E] [d2] [e2] [f2]   [g2]
;    1 [a1=Joan] [b1] [c1] [d1] [e1] [f1]   [g1]
;
; Wrap-safety analysis:
;   * _create_we_passage wraps when cx+1 == nb_columns (cx = 0-based
;     nb_columns-1). To keep column f (0-based 5) safe we set
;     nb_columns = 7 so that f -> g is a real neighbour, not a wrap.
;   * Column g (0-based 6) WOULD wrap (cx+1 == 7), so g is left
;     empty -- no we/sn entries reference g.
;   * _create_sn_passage wraps when cy+1 == nb_lines (cy = 0-based
;     nb_lines-1). To keep 1-based y=4 (0-based y=3) safe, we put
;     b4 / f4 in west_east_paths (y=4) and NEVER in south_north_paths.
;     south_north_paths only covers 1-based y=1..3.

; No y=4 in south_north_paths -- b4 and f4 must be reached via the
; west_east row above.

; English outposts along the Loire
;
; DE original, "Differences between difficulty levels" (ch. 1
; "An Unlikely Messiah"):
;
;     On Standard, there are no Guard Towers in the Burgundian town,
;     the Burgundian ambuscade at the docks has considerably fewer men,
;     and the final Burgundian force on the way to Chinon is missing
;     a Mangonel and Man-at-Arms.
;
; This chapter's English outposts are the "Burgundian town" forts: on the
; standard tier (the ``story`` semantic tier, which covers "easy" and
; "standard") their Guard Towers are removed -- see the
; ``(remove_unit ...)`` triggers below.  The other two differences
; (the ambush at the docks and the final force on the way to Chinon)
; have no counterpart in this map: there is no dock and no separate
; "final force" here, because the chapter is a single escort from
; Vaucouleurs to Chinon.
computer_only 0 0 0 0 faction britons c2 scouttower 2 militia
computer_only 0 0 0 0 faction britons d3 2 militia 1 aoe_archer
computer_only 0 0 0 0 faction britons e3 scouttower 2 militia 1 aoe_archer

; Baudricourt at b4 (real NPC npc_baudricourt -- dialogue + grants letter + escort)
computer_only 0 0 0 0 neutral faction franks b4 1 npc_baudricourt

; Dauphin's court at Chinon f4 (neutral -- receives holy_letter, allied after delivery)
; No town_center: town_center is class building with rdg 5 (would
; fire on any passing Joan unit, which looks like an unprovoked
; attack). Use just the npc_dauphin (the quest NPC) -- that's the
; unit that receives holy_letter via the receive_items mechanic.
computer_only 0 0 0 0 neutral faction franks f4 1 npc_dauphin

; ---------------------------------------------------------------------------
; STANDARD-TIER DIFFERENCE (AoE2 DE "An Unlikely Messiah").
;
;     "On Standard, there are no Guard Towers in the Burgundian town..."
;
; The ``story`` semantic tier covers "easy" and "standard" (easy is the
; equivalent of the DE's Story mode, which is even more generous than
; Standard).  On Moderate / Hard / Extreme the outposts keep their
; Guard Towers.
;
; ``(remove_unit <方格> <类型> [数量])`` deletes the tower from that
; square -- it is an engine action added for exactly this purpose (see
; soundrts/worldplayerbase/triggers.py::lang_remove_unit).
; ---------------------------------------------------------------------------
trigger computer1 (difficulty story) (remove_unit c2 scouttower)
trigger computer3 (difficulty story) (remove_unit e3 scouttower)

; Two objectives, matching the two story beats of AoE2 DE ch. 1:
;   1) 8820 "Reach Robert's garrison at Vaucouleurs"  -> completes when
;      Joan reaches Baudricourt at b4.
;   2) 8821 "Deliver the holy letter to the Dauphin at Chinon"
;      -> completes when the Dauphin receives the letter at f4.
; Previously only objective 1 existed and it was completed by the
; LETTER DELIVERY, so the objective text ("reach Vaucouleurs") did not
; match what actually happened, and 8821 was defined in tts.txt but
; never used.
trigger player1 (timer 0) (register_objective 1 2)
trigger player1 (timer 0) (add_objective 1 8820)
trigger player1 (timer 0) (add_objective 2 8821)

; Step 1: Joan (npc_joan) reaches Baudricourt at b4
; -> cut_scene "Baudricourt grants holy letter + escort"
; -> Joan receives holy_letter in inventory
; -> 4 militia + 2 aoe_knight spawn at b4 and join player1
trigger player1 (has_entered b4 npc_joan) (do (cut_scene 8826) (add_inventory_item holy_letter 1 npc_joan) (add_units b4 4 militia 2 aoe_knight) (objective_complete 1))

; Step 2: Joan carries holy_letter and GIVEs it to Dauphin at f4
; npc_has_item triggers when Dauphin receives the letter in inventory
trigger player1 (npc_has_item npc_dauphin holy_letter f4) (do (cut_scene 8830) (objective_complete 2))

; Defeat conditions
trigger player1 (key_unit_killed npc_joan) (defeat)
trigger player1 (no_unit_left) (defeat)
trigger player1 (building_lost town_center) (defeat)
