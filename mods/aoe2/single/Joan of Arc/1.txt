; 1 -- Uneasy Allies (AoE2 DE Joan of Arc, ch. 1)
;
; Story beats (DE Joan of Arc ch. 1):
;   Joan arrives at Vaucouleurs (west) and convinces Robert de
;   Baudricourt to grant her a small escort and a holy letter.
;   She then travels across English-held country to the Dauphin's
;   court at Chinon (east). Joan must survive the journey -- if
;   she dies, the war is lost.
;
; Map grid (7x4 -- a..g columns, 4 rows):
;       a       b       c       d       e       f       g   (g is buffer)
;    4 [a4] [b4=Baud.] [c4] [d4] [e4] [f4=Dau.] [g4]
;    3 [a3] [b3]   [c3] [d3=E] [e3=E] [f3]   [g3]
;    2 [a2] [b2]   [c2=E] [d2] [e2] [f2]   [g2]
;    1 [a1=Joan] [b1] [c1] [d1] [e1] [f1]   [g1]
;
; Wrap-safety analysis:
;   * _create_we_passage wraps when cx+1 == nb_columns (cx = 0-based
;     nb_columns-1). To keep column f (0-based 5) safe we set
;     nb_columns = 7 so that f -> g is a real neighbour, not a wrap.
;   * Column g (0-based 6) WOULD wrap (cx+1 == 7), so g is left
;     empty -- no we/sn entries reference g.
;   * _create_sn_passage wraps when cy+1 == nb_lines (cy = 0-based
;     nb_lines-1). To keep 1-based y=4 (0-based y=3) safe, we put
;     b4 / f4 in west_east_paths (y=4) and NEVER in south_north_paths.
;     south_north_paths only covers 1-based y=1..3.
