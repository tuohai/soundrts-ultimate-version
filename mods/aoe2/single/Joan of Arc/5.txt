; ---------------------------------------------------------------------------
; DIFFICULTY DIFFERENCES (AoE2 DE "The Siege of Paris", ch. 5)
;
;     "On Standard, there are no Onagers or Trebuchets within Paris, and
;      the Burgundian ambush is missing a few Siege Onagers and Champions.
;      On Hard, Paris is heavily fortified with Keeps and Bombard Towers,
;      the English have Monks in the city, and the Burgundian force is
;      twice as large."
;
; MAPPING NOTE -- this map has no Paris and no Burgundian player: the
; three English bridge-towns of the Loire are Meung (a1), Beaugency
; (d3) and Jallains (f5).  The DE's three effects are therefore mapped
; onto the two English fortresses of this map:
;
;   * "no Onagers or Trebuchets within Paris" -> the standard tier
;     (``story``: easy + standard) removes the Onager and the Trebuchet
;     from the central fortress Beaugency (d3).  Both are part of the
;     static ``computer_only`` line, so the baseline (moderate / hard /
;     extreme) keeps them and the standard tier loses them.
;
;   * "the Burgundian ambush is missing a few Siege Onagers and
;     Champions" -> the standard tier removes the Onager and the
;     Champion (aoe_knight) from the ambush at Jallains (f5).
;
;   * "On Hard, Paris is heavily fortified with Keeps and Bombard
;     Towers, the English have Monks in the city" -> the hard / extreme
;     tier adds a Keep, a Bombard Tower (cannontower) and two Monks to
;     Beaugency (d3).
;
;   * "the Burgundian force is twice as large" -> the hard / extreme
;     tier doubles the garrison of the ambush at Jallains (f5).
;
; ``story`` = easy + standard (the DE's Story mode is even more generous
; than Standard), ``(difficulty >= hard)`` covers hard + extreme.
; ---------------------------------------------------------------------------
