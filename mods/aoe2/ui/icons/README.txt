Optional HUD command-card / queue icons as PNG files (AoE2 mod).

Filename = type_name or order keyword, e.g. militia.png, town_center.png, train.png

Used only for:
- Command card (bottom-right)
- Production queue (bottom-left)

Map view does NOT read this folder. Map static art goes in ui/map/;
optional animations go in ui/anims/.

Size: any; scaled to 48x48 (commands) or 32x32 (queue).
If missing, a colored letter icon is generated automatically.
When the aoe2 mod is enabled, these files override res/ui/icons of the same name.
DE architecture sets (see ui/architecture.txt) live in subfolders such as
western_european/militia.png — civs that share a set share those icons.

Starter pack (flat geometric silhouettes) was generated by:
  python tools/gen_aoe2_hud_icons.py
Replace any file with better art anytime; same filename wins.
