星际 mod — 矿物与高能瓦斯
=========================


模组：``mods/starcraft`` （在 ``SoundRTS.ini`` 中 ``mods = starcraft``）。

资源
---


- 矿物（``resource1``）：按 Z 查询库存
- 高能瓦斯（``resource2``）：按 X 查询库存

地图放置：

.. code-block:: text

   mineral_field 1500 a1
   geyser 1 e1


``geyser 1`` 表示建造位点；气泉默认储量来自规则里的 ``deposit_volume``（默认 5000）。也可写成 ``geyser 5000 e1`` 指定储量。

气矿建筑
--------


同化炉 / 萃取器 / 精炼厂必须建在 **瓦斯气泉** 上（Tab 气泉再建造）。建在建造用地上会提示「不能建在那里」。

建成后的流程（对齐星际 1 母巢之战数值）：

1. 建筑吞并气泉储量（``is_an_extractor``），工人再来采集（**不是**建筑 ``auto_production`` 自灌仓）
2. 工人对气矿建筑采集，满产每趟 ``extraction_qty``（默认 **8**），并从 ``source_qty`` 扣减
3. 储量降为 0 后，每趟降为 ``depleted_production_qty``（默认 **2**），类似枯竭气泉
4. 瓦斯运回主基地等带 ``storable_resource_types resource1 resource2`` 的建筑

工人数量（``gather_slots``）
---------------------------


气矿模板默认 ``gather_slots 3``：

- **同时真正在采**的工人最多 3 个（与星际气矿饱和一致）
- 第 4 个及以后会在旁边等待，有空位再顶上
- 派 8 个工人仍能出气（会轮流采），但效率大约等于 3 人，不会变成 8 倍

实操建议：每个气矿挂 **3** 个工人即可。

神族 / 异虫补充
--------------


- 同化炉：只需气泉，**不需要**灵能场
- 萃取器：只需气泉，**不需要**菌毯
- 水晶塔可建在场外（自己提供灵能）；光子炮须在灵能场内，断电不能攻击

查看属性
--------


选中气矿建筑，按 V 打开属性界面，可听到需要矿床、当前矿脉储量等。

规则关键字详见 ``mod/modding.rst`` （Economy 与「矿床与气矿」两节）。

测试图：``mods/starcraft/multi/sc_resources_test.txt``。
